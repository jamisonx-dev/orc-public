MODULE SERVERS — play a module on another card through that card's own jackd

main = the main jackd. Picking a card starts that card's own jackd and moves the module there; it plays straight to that card's outputs. Its ports show in the grid under "<card> server". You can also just CONNECT a module's outputs to another server's ports in the grid: the module moves to that server and is wired only there (its old wires go). Changing it restarts the module (a second or two of silence). Saved across reboots. A card's own server stops by itself when no module uses it.
