Perform-VE

Live control of the TC-Helicon Perform-VE over USB MIDI (ch 1). The box doesn't report its settings back, so these controls only send values and don't show its current state. Audio sent to its USB in ch 3 comes back processed, so it works as an insert effect with no cables (INSERT card below).

INSERT · ROUTE A MODULE THROUGH THE PERFORM-VE (USB, CABLE-FREE)

Sends the chosen module into USB-in ch3 and returns the processed sound to the main out. It is added to the module's own output; mute that on /patch to hear only the processed sound. To wire it by hand on /patch: source → PERFORMVE OUT 3, PERFORMVE IN 1/2 → main.
