Screens & icons
New icon ×

Icons are small canvases you can animate and then place on a screen with the Stamp tool. The starting screens are examples with made-up values, not live ORC data.

Preview

Real size uses your screen's idea of a millimetre, which is often a little off. A real TFT also looks less saturated and shifts colour off-angle. The previews play along with the animation.

Import image

The image goes into the current frame. Changing these re-applies it. Undo restores what was there before.

Export

PNG, sprite sheet and GIF cover the selected screen or icon. The zip holds, for every screen and icon, a PNG, a C header and a raw .bin (all frames), plus a sprite sheet and GIF when it is animated, and the project file. TFT data is RGB565, high byte first. OLED data comes in SSD1306 page order and plain row order.
